# Humanize and remove AI watermarks

Apply after every rewrite loop and before final PDF.

## Voice rules

- Prefer concrete verbs and owned outcomes: shipped, reduced, migrated, debugged, owned, designed.
- Name real tools, versions only if meaningful, systems, and scale.
- One idea per bullet; vary sentence openings.
- Keep the candidate's factual claims; clarify, don't inflate.

## Ban / rewrite these (and close variants)

- "Passionate about…" / "Results-driven…" / "Detail-oriented professional"
- "Leveraged … to synergize…" / "utilized" when "used" works
- "In today's fast-paced…" / "Cutting-edge" / "Robust" / "Seamless" / "Holistic"
- "Proven track record" / "Eager to contribute" / "Dynamic environment"
- "Responsible for" as empty filler — say what was delivered
- "Excited to…" summaries; empty soft-skill stacks without evidence
- Templated triple-adjective openers ("Highly motivated, dedicated, innovative…")
- Em-dash heavy AI cadence; identical bullet rhythms across every role

## Watermark / tell checks

- No invisible Unicode, white text, or keyword walls for ATS gaming (this repo's public analyses call that out — do not do it).
- No placeholder lorem / "Company Name" / "X%" left behind.
- Links must be real URLs from memory.

## Quick pass

1. Delete banned phrases.
2. Add missing metrics from memory.
3. Ensure each bullet answers: action + object + tool/context + result.
4. Read aloud mentally — if it sounds generic, rewrite once more.
