# Upfront intake questions (Step 1)

Ask **all** of these in the **first** skill message (skip only fields already complete in `.resume-memory/profile.json`; confirm those instead). Do not drip later.

## Identity and contact

1. Full name (as it should appear on the resume)
2. Professional email
3. Phone (with country code if applicable)
4. Location (city, region/country; remote preference if relevant)
5. Target role / job title(s) you are applying for

## Links (include every URL you want on the resume)

6. GitHub URL
7. LinkedIn URL
8. Portfolio / personal site URL (or "none")
9. Other links (LeetCode, blog, Google Scholar, Behance, etc.) — list each with label + URL

## Experience

10. For each role (most recent first): company, title, location, start–end dates, employment type; 3–6 bullets with **what you owned**, **stack/tools**, and **metrics** (%, $, time, scale, users)
11. Internships, contract, freelance, research, teaching — same structure
12. Gaps or constraints to respect (NDAs, cannot name employer, etc.)

## Projects

13. For each project: name, one-line purpose, your role, tech stack, links (repo / demo), outcomes/metrics, whether open-source contribution vs personal

## Education

14. School, degree, field, dates, GPA (optional), relevant coursework, honors

## Skills

15. Languages, frameworks, tools, cloud, databases, soft skills you want listed — grouped how you prefer
16. Skills you do **not** want claimed

## Achievements and extras

17. Awards, publications, competitions, open-source programs (e.g. GSoC), certifications
18. Volunteer / leadership worth listing
19. Languages (human) and proficiency

## Metrics and proof

20. Strongest quantified wins (paste numbers you can stand behind)
21. Anything the JD might ask that is not above

## Constraints

22. Page limit preference (default **2**), must-keep sections, must-drop sections
23. Tone (more academic / more industry / founder)
24. Work authorization or other footer notes only if you want them on the resume
25. Preferred filename slug (e.g. `FirstLast_Company_Role`)

## Memory

26. If updating an existing profile: what should change vs stay?

After answers, write/merge `.resume-memory/profile.json` before asking for the template (Step 2).
