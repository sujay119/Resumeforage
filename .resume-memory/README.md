# Resume memory

Durable profile store for the **best-fit-resume** skill.

| File | Purpose |
|------|---------|
| `profile.json` | Your filled profile (local; gitignored) |
| `profile.schema.json` | Shape reference for agents |

Created/updated automatically when the skill runs. Explicit commands: "update my resume memory", "save my profile", etc.

Do not commit `profile.json` if it contains personal contact data.
